Learning cadence

Intraday pulse 15 min

Live inference, reasoning agent, daytrade manifest. Runs every 15 minutes during regular trading hours.

Daily close after close

Investor v3 retrain, swing manifest, sentiment + congress enrichment.

Weekly deep Sunday

Full Predictor v3 retrain (~2.5h) plus champion/challenger promotion gates for both brains.

Execution is prep-only. Nostradamus never places live trades. It writes JSON manifests that external Robinhood Agents poll via /api/trading/manifest and /api/daytrade/manifest. Full runbook in docs/GLORIOUS_STACK.md.  ·  Two accuracy numbers? V2 (63.7%) uses a looser split; Predictor v3 (52.9%) uses a strict walk-forward holdout (train ≤2023, test ≥2025).
